✨ KEY FEATURES & ARCHITECTURE
--------------------------------------------------
🤖 100% On-Device AI Engine: Powered by Google LiteRT-LM running Gemma 3 (584 MB) locally on-device. Features an instant 7-step guided setup wizard and natural language sentiment analyzer.
